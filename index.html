My computer was heavily bugging out and broke two of the features because I was running so many LLMs.
TLDR: I wanted to make an always-on independent AI that talked and generated UI on the fly. I first recreated Poke and added so that it could call you out of the blue or send you UIs it made. Then I made it so that you could interact with these UIs on the web while on the phone, and then multiplied it to many LLMs in parallel that act as one. Instead of acting sequentially or as different agents, imagine one agent that can check wallets, use the browser, and have shared memory (inspired by Thinking Machines, but using off-the-shelf LLMs).
